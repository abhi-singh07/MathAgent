To solve the problem, we start by defining the number of red socks as \( r \) and blue socks as \( b \), with the total number of socks \( n = r + b \leq 1991 \). The probability that two
randomly selected socks are both red or both blue is given as \( \frac{1}{2} \). This leads to the equation:

\[
\frac{\binom{r}{2} + \binom{b}{2}}{\binom{n}{2}} = \frac{1}{2}
\]

Substituting \( b = n - r \) and simplifying, we find that \( n \) must be a perfect square, say \( n = k^2 \). The
number of red socks \( r \) is then given by:

\[
r = \frac{k^2 + k}{2}
\]

The largest \( k \) such that \( k^2 \leq 1991 \) is 44, giving \( n = 1936 \) and \( r = 990 \). Verifying, the probability is exactly \( \frac{1}{2} \).

Thus, the largest possible number of red socks
is:

\[
\boxed{990}
\]

```python
import math

def max_red_socks():
    max_total = 1991
    k = int(math.isqrt(max_total))
    while k >= 1:
        n = k * k
        if n > max_total:
            k -= 1
            continue
        r = (n + k) // 2
        return r
        k -= 1
    return 0

#
Execute the function
result = max_red_socks()
print("The largest possible number of red socks is", result)
```

\[\frac{r(r-1)}{(r+b)(r+b-1)}+\frac{b(b-1)}{(r+b)(r+b-1)}=\frac{r(r-1)+(t-r)(t-r-1)}{t(t-1)}=\frac{1}{2}.\]

\[r=\frac{t\pm\sqrt{t}}{2}\, .\]
