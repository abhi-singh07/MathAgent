To evaluate the product \(\prod_{n = 1}^{2004} \frac{n^2 + 2n - 1}{n^2 + n + \sqrt{2} - 2}\), we can simplify each term and recognize a telescoping pattern.

1. **Factor the Numerator and Denominator:**
   - Numerator: \(n^2 + 2n - 1 = (n + 1 -
\sqrt{2})(n + 1 + \sqrt{2})\)
   - Denominator: \(n^2 + n + \sqrt{2} - 2 = (n + 1 - \sqrt{2})(n + \sqrt{2})\)

2. **Simplify Each Term:**
   \[
   \frac{(n + 1 - \sqrt{2})(n + 1 + \sqrt{2})}{(n + 1 - \sqrt{2})(n + \sqrt{2})} = \frac{n + 1 + \sqrt{2}}{n + \sqrt{2}}
   \]

3. **Recognize the
Telescoping Product:**
   \[
   \prod_{n=1}^{2004} \frac{n + 1 + \sqrt{2}}{n + \sqrt{2}} = \frac{2 + \sqrt{2}}{1 + \sqrt{2}} \cdot \frac{3 + \sqrt{2}}{2 + \sqrt{2}} \cdot \ldots \cdot \frac{2005 + \sqrt{2}}{2004 + \sqrt{2}}
   \]
   Most terms cancel out, leaving \(\frac{2005 + \sqrt{2}}{1 +
\sqrt{2}}\).

4. **Rationalize the Denominator:**
   \[
   \frac{2005 + \sqrt{2}}{1 + \sqrt{2}} \times \frac{1 - \sqrt{2}}{1 - \sqrt{2}} = \frac{(2005 + \sqrt{2})(1 - \sqrt{2})}{-1} = 2004\sqrt{2} - 2003
   \]
