**Problem:** How many integers \( n \) satisfy \( 0 < n < 60 \) and \( 4n
\equiv 2 \pmod{6} \)?

**Solution:**

1. **Understand the Congruence:**
   We start with the congruence equation:
   \[
   4n \equiv 2 \pmod{6}
   \]
   This means that when \( 4n \) is divided by 6, the remainder is 2.

2. **Simplify the Equation:**
   To simplify, divide both sides of the equation
by 2 (since 2 is a common factor of 4, 2, and 6):
   \[
   2n \equiv 1 \pmod{3}
   \]
   This step is valid because dividing the modulus 6 by its greatest common divisor with 4 (which is 2) reduces the modulus to 3.

3. **Find the Multiplicative Inverse:**
   We need to find an integer \( x \) such
that:
   \[
   2x \equiv 1 \pmod{3}
   \]
   Testing small integers:
   - \( x = 2 \) satisfies \( 2 \times 2 = 4 \equiv 1 \pmod{3} \).

4. **Solve for \( n \):**
   Multiply both sides of \( 2n \equiv 1 \pmod{3} \) by the inverse \( x = 2 \):
   \[
   n \equiv 2 \times 1 \pmod{3} \implies n \equiv
2 \pmod{3}
   \]
   Therefore, \( n \) can be expressed as:
   \[
   n = 3k + 2 \quad \text{for some integer } k
   \]

5. **Determine the Range of \( k \):**
   Given \( 0 < n < 60 \):
   \[
   0 < 3k + 2 < 60
   \]
   Subtract 2 from all parts:
   \[
   -2 < 3k < 58
   \]
   Divide by 3:
   \[
  
-\frac{2}{3} < k < \frac{58}{3} \approx 19.333
   \]
   Since \( k \) must be an integer, \( k \) ranges from 0 to 19.

6. **Count the Number of Solutions:**
   The integer values of \( k \) are 0, 1, 2, ..., 19, which gives us 20 values.
