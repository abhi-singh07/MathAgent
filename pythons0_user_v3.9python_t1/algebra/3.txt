**Problem Statement:**
You have the following terms of an arithmetic sequence: \(\frac{1}{2}, x-1, 3x, \ldots\). Solve for \(x\).

**Step-by-Step Solution:**

1. **Understand the Properties of an
Arithmetic Sequence:**
   - In an arithmetic sequence, the difference between consecutive terms is constant.
   - This means the difference between the second and first term is equal to the difference between the third and second term.

2. **Set Up the Equation Based on the Common Difference:**
  
\[
   (x - 1) - \frac{1}{2} = 3x - (x - 1)
   \]

3. **Simplify the Equation:**
   \[
   x - 1 - \frac{1}{2} = 3x - x + 1
   \]
   \[
   x - \frac{3}{2} = 2x + 1
   \]

4. **Solve for \(x\):**
   \[
   x - 2x = 1 + \frac{3}{2}
   \]
   \[
   -x = \frac{5}{2}
   \]
   \[
   x = -\frac{5}{2}
   \]

5.
**Verify the Solution:**
   - Substitute \(x = -\frac{5}{2}\) back into the terms:
     \[
     \text{First term: } \frac{1}{2}
     \]
     \[
     \text{Second term: } -\frac{5}{2} - 1 = -\frac{7}{2}
     \]
     \[
     \text{Third term: } 3 \times -\frac{5}{2} = -\frac{15}{2}
     \]
   - Check
the common difference:
     \[
     -\frac{7}{2} - \frac{1}{2} = -\frac{8}{2} = -4
     \]
     \[
     -\frac{15}{2} - (-\frac{7}{2}) = -\frac{8}{2} = -4
     \]
   - The common difference is consistent, confirming the solution is correct.

**Final Answer:**
\[
\boxed{-\dfrac{5}{2}}
\]
