- `b(i)`: Number of valid sequences ending with a single no-mail (N) at house `i`.
- `c(i)`: Number of valid sequences ending with two no-mails (NN) at house `i`.

###
Recurrence Relations:
Based on the constraints, we can establish the following recurrence relations:
1. `a(i) = b(i-1) + c(i-1)`: If the `i-th` house gets mail, the previous house can either end with a single no-mail or two no-mails.
2. `b(i) = a(i-1)`: If the `i-th` house does not get mail, the
previous house must have received mail.
3. `c(i) = b(i-1)`: If the `i-th` house does not get mail and the previous house also did not get mail, the house before that must have received mail.

- `b(2) = 1`: Only one way to end with a single no-mail (M, N).
- `c(2) = 1`: Only one way
