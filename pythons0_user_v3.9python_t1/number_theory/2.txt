Problem: A rectangular array of chairs is an arrangement of the chairs in rows and columns such that each row contains the same number of chairs as every other row and each column contains the same number of chairs as every other column.  If there must be at least two chairs in every row and column and all
of the chairs in the room must be included, how many arrays are possible in a classroom containing $36$ chairs? Note that $12$ rows of $3$ chairs is different from $3$ rows of $12$ chairs.
